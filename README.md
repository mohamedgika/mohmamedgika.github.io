# Portfolio

Personal portfolio of **Mohamed Ashraf** — Software Engineer. Live at https://mohamedgika.github.io/mohmamedgika.github.io/

A single static page with no build step and no third-party JavaScript:

- `index.html` — markup and inline SVG icons
- `css/main.css` — styles, dark/light themes, animations
- `js/app.js` — scroll reveals, typing effect, counters, skill bars, project filters, tilt and magnetic hover effects, contact form
- `images/` — WebP images
- `CV/` — downloadable resume

Animations respect the visitor's `prefers-reduced-motion` setting.
